# Bidak Catur (set Chessnut)

File-file di folder ini adalah bidak catur klasik bergaya halus — pengganti
gaya visual bidak chess.com (bidak asli chess.com bersifat hak milik dan
tidak dapat disalin).

- Set: **Chessnut**
- Penulis: Alexis Luengas — https://github.com/LexLuengas
- Sumber: https://github.com/lichess-org/lila/tree/master/public/piece/chessnut
- Lisensi: **Apache 2.0** — https://github.com/LexLuengas/chessnut-pieces/blob/master/LICENSE.txt

Bidak dipakai di seluruh situs lewat komponen `ChessPiece`
(`src/halaman/Beranda/ChessPieceSvg.jsx`).
